# Studieverktøy

En enkel webapp for oppgavehåndtering og brukerautentisering.

## Funksjoner
- Brukerinnlogging, registrering og oppdatering av profil.
- Legg til, vis og administrer oppgaver med filtre.
- Responsivt mørkt tema.
- Tabeller tilpasser seg alle skjermstørrelser.

## Hvordan bruke
1. Sett opp databasen i `config/config.php`.
2. Registrer deg og logg inn for å administrere oppgaver.
